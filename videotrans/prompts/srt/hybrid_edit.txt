# TASK
You receive subtitle blocks from a Hybrid recognition pipeline. Each block has:
- `Audio_ASR`: speech recognition text. This is the main text.
- `Video_OCR`: text read from the on-screen subtitle. It can contain noise.

Propose minimal corrections to `Audio_ASR`, only where `Video_OCR` clearly shows the correct word or spelling, or where `Audio_ASR` has an obvious recognition error.

# RULES
- Do not rewrite a block. Propose only word or phrase replacements.
- Each "original" phrase must appear exactly, character for character, in `Audio_ASR` of that block.
- Make the "original" phrase long enough (add neighbouring words if needed) so that it appears only once in that block.
- Keep the meaning. Never add, remove or summarise content.
- Do not change numbers, names or facts unless `Video_OCR` shows the correct form.
- Do not change only capitalisation or punctuation.
- Keep the language of each block.
- If a block needs no change, propose nothing for that block.

# OUTPUT
Wrap the output in <EDITS> tags. One edit per line, exactly in this form:
<block index> | <original phrase from Audio_ASR> | <replacement>
No other text.

# EXAMPLE
Input:
[3]
Audio_ASR: Tới đây rồi nhà mình có tất pin gì bỏ vô
Video_OCR: topping gì bỏ vô
Output:
<EDITS>
3 | tất pin | topping
</EDITS>
